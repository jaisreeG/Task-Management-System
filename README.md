# Task Management System

The **Task Management System** is a console-based Java application developed to help users organize and manage daily tasks efficiently. It provides a simple menu-driven interface to create, view, search, update, and delete tasks while tracking their completion status. The project demonstrates the practical application of core Java programming concepts in building a real-world utility.

## Purpose
- Organize and manage daily tasks efficiently.
- Practice Object-Oriented Programming (OOP) concepts.
- Demonstrate CRUD operations using Java Collections.

## Features
- Add new tasks
- View all tasks
- Search tasks by title
- Mark tasks as completed
- Delete tasks
- Menu-driven user interface

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList (Java Collections)
- Exception Handling
- Scanner & Iterator
